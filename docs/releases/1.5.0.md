# BeeBranch 1.5.0

Confirm actions without leaving the workspace, do more from a file's context menu, and work through a calmer changes panel and diff toolbar.

## Added

- **Action bar for confirmations**: force push, push rejection, merge or rebase by drag and drop, branch publication, deletions, discards and aborts now ask for confirmation in a bar above the workspace instead of a modal dialog. Destructive actions take two steps in the same bar — the action, then an explicit warning with Confirm / Cancel, focus starting on Cancel. Escape cancels.
- **Publishing a local branch**: creating a branch the remote does not know yet, or pushing a branch without upstream, asks for confirmation in the action bar. Confirming pushes it to `origin/<branch>` with `--set-upstream`, so the first push creates the remote branch and records its upstream in one explicit step.
- **Richer file context menu**: an *Ignore* submenu offers the file itself, every file with the same name, every file with the same extension, or its folder. Ignoring a tracked file adds the pattern to `.gitignore` and untracks the file after a confirmation; it stays on disk and its removal is staged. The menu can also stash a single file, open it in the external diff tool or its default program, show it in Finder or the file manager, save its changes as a patch, open its history, and edit it in-app.
- **Keyboard shortcuts**: Escape closes the central editor (diff, tool) and then the inspector, one panel per press. `Mod+W` closes the active repository tab through the existing close confirmation. On macOS, `Cmd+W` no longer quits the application.

## Changed

- Destructive actions no longer require typing the branch, tag, path or `abort`: the backend policy requires an explicit acknowledgement, and the two-step bar replaces the typed text.
- **Diff toolbar**: actions, display modes and navigation are grouped. Hunk and file navigation carry a visible label, and word wrap shows when it is on.
- **Changes panel**: the checkbox, stage and `···` controls of a file row appear on hover, keyboard focus or selection, and every checkbox stays visible during a multi-selection. *Discard the selection…* is disabled until something is selected.
- **Error banners** in the workspace can be dismissed and share the layout of the application banner.

## Notes

- Untracking an ignored file stages its removal from the repository: other clones lose the file at their next pull, while the local copy stays on disk.
- On Linux, *Show in file manager* opens the parent folder: `xdg-open` cannot select a file.
