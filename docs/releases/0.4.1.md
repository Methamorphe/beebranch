# BeeBranch 0.4.1

## Graph references

- A local branch and its remote mirror on the same commit
  (`main`, `origin/main`) now count as **a single** reference:
  no more misleading `+1`, and no hover menu when there is nothing to
  distinguish. The tooltip gives the name and type (`main · locale`).
- Each badge has an icon: fork for a local branch, cloud for
  a remote branch, label for a tag. A commit's menu uses the
  same icons and specifies `locale` / `distante` / `tag`.
- A branch ahead of or behind its upstream remains displayed on both
  affected commits, each with its own badge: nothing is merged when
  the commits differ.
- The menu retains all the commit's references (including the
  `origin/main` mirror): double-clicking a remote reference creates the
  corresponding local branch, as before.

## Update

This version is signed with the same key as 0.4.0: from the installed
application, Settings → Updates → “Check” offers 0.4.1, and
“Return to the previous version” goes back to 0.4.0 via `rollback.json`.

Non-notarized macOS Apple Silicon build: Gatekeeper requests permission on
first launch (`xattr -dr com.apple.quarantine /Applications/BeeBranch.app`).
