# BeeBranch 0.4.1

## Références du graphe

- Une branche locale et son miroir distant posés sur le même commit
  (`main`, `origin/main`) comptent désormais pour **une seule** référence :
  plus de `+1` trompeur, et plus de menu au survol quand il n'y a rien à
  départager. L'infobulle donne le nom et le type (`main · locale`).
- Chaque badge porte une icône : fourche pour une branche locale, nuage pour
  une branche distante, étiquette pour un tag. Le menu d'un commit reprend les
  mêmes icônes et précise `locale` / `distante` / `tag`.
- Une branche en avance ou en retard sur son upstream reste affichée aux deux
  commits concernés, chacun avec son propre badge : rien n'est fusionné quand
  les commits diffèrent.
- Le menu conserve toutes les références du commit (y compris le miroir
  `origin/main`) : le double-clic sur une référence distante crée la branche
  locale correspondante, comme avant.

## Mise à jour

Cette version se signe avec la même clé que 0.4.0 : depuis l'application
installée, Réglages → Mises à jour → « Vérifier » propose 0.4.1, et
« Revenir à la version précédente » repasse à 0.4.0 via `rollback.json`.

Build macOS Apple Silicon non notariée : Gatekeeper demande une autorisation au
premier lancement (`xattr -dr com.apple.quarantine /Applications/BeeBranch.app`).
