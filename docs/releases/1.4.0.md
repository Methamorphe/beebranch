# BeeBranch 1.4.0

Manage files directly from the changes panel, find commits without leaving the graph, and move through diffs from the keyboard.

## Added

- **File context menu** (#26): right-click a file in the changes panel to open the same actions as the row `···` menu — stage or unstage it, open it in the configured editor, ignore an untracked file by file, extension or folder, discard its unstaged edits, and copy its path. A single action list feeds both entry points, so the row menu remains the keyboard-reachable path to every action.
- **File deletion** (#26): delete a file from the working tree after an explicit confirmation. Only a regular file or a symbolic link inside the worktree is removed: directories are refused, a path whose parent resolves outside the worktree is rejected, and a link is unlinked instead of followed. The deletion is journaled as a destructive operation. A tracked file can be restored from the index; an untracked file is permanently lost.
- **Find in the history graph** (#23): `Mod+F` opens a find bar over the commits already loaded in the graph. Search runs on the subject, author and SHA prefix; Enter and ↑/↓ move through matches and reveal them, Escape closes the bar. Focused editors and inputs keep their own `Mod+F`, and Deep Search remains on `Mod+Shift+F` for the full history.
- **Keyboard navigation between diff files** (#25): `←`/`→` and `↑`/`↓` move between files of a multi-file diff; the active file stays scrolled into view. Editable fields, dialogs and menus keep those keys. Opening a file from the commit detail now loads the full commit diff and selects the requested file instead of filtering the report to that path, so the arrows have the complete file list.

## Notes

- File deletion targets the worktree only. It does not stage a `git rm`: the deletion appears as an unstaged change that can be discarded back from the index.
- Ignored directories, submodules and conflicted entries do not offer deletion; there is no bulk deletion.
