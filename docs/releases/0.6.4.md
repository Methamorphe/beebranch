# BeeBranch 0.6.4

## Créer un dépôt local

- Depuis l’accueil, le menu « Ajouter un dépôt » ou la palette de commandes,
  « Créer un dépôt local… » initialise un dépôt Git dans un dossier nouveau ou
  existant non versionné.
- Le dossier parent et le nom se choisissent dans un dialogue, avec un aperçu
  du chemin. La branche initiale est optionnelle : laissée vide, Git applique
  `init.defaultBranch`.
- Les fichiers déjà présents ne sont ni déplacés ni supprimés ; ils restent non
  suivis. Un dossier qui contient déjà un dépôt (worktree ou bare) est refusé
  avec un message explicite.
- Le dépôt est ouvert immédiatement dans un nouvel onglet et ajouté aux dépôts
  récents.

## Zoom de l’interface

- ⌘/Ctrl + `+` ou `-` ajuste le zoom natif de l’interface par paliers de 20 % ;
  ⌘/Ctrl + `0` revient à 100 %.
- Le zoom s’applique partout, y compris aux dialogues et à la palette. Sur
  macOS et Linux, Ctrl + molette fonctionne aussi.
- Les raccourcis sont rappelés dans Réglages → Raccourcis clavier.
