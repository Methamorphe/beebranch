# BeeBranch 0.6.4

## Create a local repository

- From home, the “Add a repository” menu or the command palette,
  “Create a local repository…” initializes a Git repository in a new or
  existing unversioned directory.
- The parent directory and name are chosen in a dialog, with a preview
  of the path. The initial branch is optional: left empty, Git applies
  `init.defaultBranch`.
- Files already present are neither moved nor deleted; they remain
  untracked. A directory that already contains a repository (worktree or bare) is rejected
  with an explicit message.
- The repository opens immediately in a new tab and is added to recent
  repositories.

## Interface zoom

- ⌘/Ctrl + `+` or `-` adjusts the interface's native zoom in 20% steps;
  ⌘/Ctrl + `0` returns to 100%.
- Zoom applies everywhere, including dialogs and the palette. On
  macOS and Linux, Ctrl + wheel also works.
- The shortcuts are recalled in Settings → Keyboard shortcuts.
