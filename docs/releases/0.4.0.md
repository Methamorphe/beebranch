# BeeBranch 0.4.0 — P3

## Explicit undo actions

- Undo/redo covers the Git matrix: commit, amend, checkout, branches, tags,
  remotes, stash create, worktrees, completed and in-progress merge/rebase/cherry-pick/revert
  (typed abort), soft/mixed reset.
- No application backup: only Git refs, index and objects are
  restored. A violated precondition causes rejection without effects.
- A partial failure displays the step, command and recovery SHA
  (`git reflog`). An interrupted restore is marked at startup and
  is never retried automatically.

## Drag and drop

- Dropping a branch onto another opens a merge/rebase preview: affected
  commits, fast-forward, clean or dirty worktree, checkout conflict.
- No mutation before confirmation. Canceling before the drop changes
  nothing. Conflicts are still resolved in the Conflicts view.
- Commits in the rebase plan can be reordered by drag and drop.

## Design system and accessibility

- Complete tokens (spacing, typography, depth, motion),
  light/dark/system themes, compact or comfortable density.
- Single dialog primitive (focus trap, focus restoration, inert
  background) and design system button.
- Skip link, keyboard navigation, announced error messages, contrasts
  checked automatically in both themes.

## Large repositories

- The graph streams `git log`: deep pages no longer traverse
  the entire prefix. On `linear-1m`, adding 10 pages drops from 38.6 s to 18 ms
  (local measurement, deterministic corpus).

## Workspaces

- Local groups of up to 20 repositories, multi-repository fetch/pull with four
  bounded workers, per-repository results, isolated failures, sessions closed after
  the action.

## Distribution

- Windows/macOS/Linux packaging, macOS signing and notarization, Windows
  signing, signed update artifacts.
- Signed update: a missing or invalid signature is rejected.
- Signed rollback via `rollback.json` (previous version retained).
- No telemetry: automated source audit, only GitLab,
  Git and update manifest connections are possible.

## Limitations

- Signature, installation and rollback tests run in the
  CI matrix; installation on a clean machine is not reproducible in
  the development environment.
