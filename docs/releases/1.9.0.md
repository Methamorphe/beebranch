# BeeBranch 1.9.0

The interface is readable by default: wider rows, explicit file glyphs, a structured commit detail, and outlined primary controls — with the same accent yellow.

## Changed

- **Readability ships by default**: history rows and file rows sit on a 32 px height on the 8 px grid. File rows carry pencil / plus / minus glyphs, the folder reads grey and the path uses the interface sans font. The commit detail spells out its title and lays its Author / Date / Parents / Signature grid, with an outlined primary action. Only three controls take an outline: creating a local branch (`+`), closing an inspector (`×`) and the default action menu (`···`).

## Fixed

- **Arrow keys walk the changes panel**: ↑/↓ (and Home/End) move between the files of *To stage* / *Ready to commit* and put the focus on the file path before opening its diff, instead of landing on the row checkbox; ↓ from the filter opens the first file and ↑ from the first file returns to it, while ←/→ collapse or expand a folder in tree mode.
- **The upstream selector shows this branch's remotes only**: right-clicking a local branch lists the remote-tracking copies of that branch (`main` → `origin/main`, `github/main`) rather than every remote branch. Symbolic refs stay out, the current upstream is marked, and the empty state says this branch has no remote copy yet.
