# BeeBranch 0.6.1

## Selecting a range of commits

- A click on a commit, then Maj+clic on another: all commits between
  the two are selected and the A → B diff opens in the inspector, to the right of the
  graph, without leaving history.
- Maj+↑/↓ extends the same range with the keyboard. The selection is ordered from oldest
  to newest, the application order of Cherry-pick and Revert.
- “Compare” now accepts any selection of two or more commits; beyond
  four commits, the order list compacts to `N commits · sha…sha`.

## Range diff readable like GitKraken

- The panel header announces the number of selected commits and
  “Diff of N commits”, then lists each compared commit (subject, date, author,
  SHA), from newest to oldest.
- Files leave the flat list: collapsible tree, single-child
  directories compacted (`src/app/components`), Path / Tree toggle.
  The open file keeps its path, its `+N/−N` and its hunk count
  above the diff.
- In Unified mode, the words actually modified are underlined as in Side-by-side
  instead of an entire monochrome line.

## Verifications
