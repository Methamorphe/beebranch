# BeeBranch 1.6.1

A fix for the draft commit message added in 1.6.0: it no longer sits in the way of selecting the local changes.

## Fixed

- **WIP row**: the commit message is now a label until you double-click it (or focus it and press Enter/F2). A single click anywhere on the `// WIP` row opens the changed files, as before 1.6.0, so selecting the row never lands in a text field. Enter or Escape leaves the field; the draft remains shared with the commit panel in both directions.

## Notes

- The update artifact is signed with the same key as 1.6.0: Settings → Updates offers 1.6.1, and “Return to the previous version” goes back to 1.6.0 through `rollback.json`.
