# BeeBranch 0.5.1

## Comparer deux commits par Maj+clic

- Sélectionnez un commit, puis Maj+clic sur un second : le diff A → B s'ouvre
  directement dans la vue Comparaison, sans passer par les options
  d'affichage.
- Le premier commit sélectionné (ou le dernier coché) sert de base ; le couple
  reste sélectionné dans le graphe.
- « Sélection multiple » reste disponible pour cocher plus de deux commits,
  puis « Comparer A → B ». Aucune mutation du dépôt n'est effectuée.

## Graphe de l'historique redessiné

- Les couleurs de branche restent confinées à la colonne du graphe : les bandes
  teintées qui coloraient la ligne entière disparaissent. La sélection se
  marque par un léger relief de surface et un repère d'accent à gauche.
- Les voies sont tracées d'un seul trait continu, sans transparence
  superposée : les fourches ne forment plus de taches plus sombres.
- Les courbes de parenté sont lissées, les pastilles de commit sont dessinées
  au-dessus de toutes les arêtes et le halo gris est remplacé par un anneau à
  la couleur du fond, qui interrompt proprement la voie.

## Étiquette HEAD lisible

- Le libellé et l'icône de la branche courante utilisaient le jaune d'accent
  sur un fond jaune d'accent (contraste ≈ 1,2:1). Ils utilisent désormais
  `--accent-contrast` (contraste ≈ 10:1), comme les autres contrôles remplis
  d'accent.

## Mise à jour

- Le build macOS Apple Silicon est désormais signé `Developer ID Application:
  beecoming (JFSQ98955P)`, notarié par Apple et agrafé (app et DMG). Gatekeeper
  ne demande plus de contournement au premier lancement.
- L'identité de signature change par rapport aux versions précédentes : macOS
  peut redemander une fois l'accès au trousseau et aux dossiers choisis.
- La clé de mise à jour reste identique : « Revenir à la version précédente »
  repasse à 0.5.0 via `rollback.json`.
