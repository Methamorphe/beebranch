# BeeBranch 0.5.1

## Compare two commits with Maj+clic

- Select a commit, then Maj+clic on a second: the A → B diff opens
  directly in the Comparison view, without going through the display
  options.
- The first selected commit (or the last checked one) serves as the base; the pair
  remains selected in the graph.
- “Multiple selection” remains available to check more than two commits,
  then “Compare A → B”. No repository mutation is performed.

## Redesigned history graph

- Branch colors remain confined to the graph column: the tinted
  strips that colored the entire row are gone. Selection is
  marked by a slight surface elevation and an accent marker on the left.
- Lanes are drawn as a single continuous stroke, without overlapping
  transparency: forks no longer form darker patches.
- Parent curves are smoothed, commit dots are drawn
  above all edges and the gray halo is replaced by a ring in
  the background color, cleanly interrupting the lane.

## Readable HEAD label

- The current branch's label and icon used the accent yellow
  on an accent yellow background (contrast ≈ 1.2:1). They now use
  `--accent-contrast` (contrast ≈ 10:1), like the other accent-filled
  controls.

## Update

- The macOS Apple Silicon build is now signed with a
  `Developer ID Application` certificate, notarized by Apple and stapled (app and DMG). Gatekeeper
  no longer requires a workaround on first launch.
- The signing identity changes from previous versions: macOS
  may request access to the OS keychain and chosen directories once again.
- The update key remains the same: “Return to the previous version”
  goes back to 0.5.0 via `rollback.json`.
