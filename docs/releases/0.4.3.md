# BeeBranch 0.4.3

## Release de vérification

Aucun changement fonctionnel : cette version ne sert qu'à valider la chaîne de
mise à jour sur une machine réelle.

- La mise à jour doit apparaître seule dans l'en-tête (icône de téléchargement
  avec point d'accent) sans ouvrir les réglages.
- L'installation doit relancer l'application d'elle-même sur 0.4.3, sans
  quitter ni rouvrir à la main.
- Le trousseau ne doit **plus** demander le mot de passe au lancement suivant :
  l'autorisation « Toujours autoriser » accordée sur 0.4.2 est liée à une
  signature stable (Apple Distribution : Nala Multimedia) et se transmet à cette
  version.

Retour arrière disponible : `rollback.json` pointe 0.4.2, signé, installable
depuis Réglages → Mises à jour.
