# BeeBranch 0.4.3

## Verification release

No functional changes: this version only serves to validate the update
chain on a real machine.

- The update must appear on its own in the header (download icon
  with an accent dot) without opening settings.
- Installation must relaunch the application on its own on 0.4.3, without
  manually quitting or reopening it.
- The OS keychain must **no longer** ask for the password on the next launch:
  the “Always Allow” permission granted on 0.4.2 is tied to a
  stable signature (Apple Distribution: Nala Multimedia) and carries over to this
  version.

Rollback available: `rollback.json` points to 0.4.2, signed, installable
from Settings → Updates.
