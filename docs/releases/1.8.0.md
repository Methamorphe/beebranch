# BeeBranch 1.8.0

The whole repository's CI in one place, and a branch switch that only asks when something actually stands in its way.

## Added

- **Pipeline history**: the repository navigator has a *Pipelines* section listing the linked project's pipelines across every ref — branches, tags and merge requests — newest first, with pagination. Selecting one shows its jobs by stage with their status and duration inside the application; the pipeline and every job open on the forge. The toolbar indicator still reports the checked-out commit, and its panel now switches between a *Commit* and a *Repository* scope.

## Changed

- **Branch switch runs without asking**: checking out a local branch or a commit from the branch menus, the graph, a review request or the status bar switches directly when Git would accept it. Only a checkout Git would refuse (operation in progress, unresolved conflicts) or one that would move an existing local branch onto a remote branch reads its summary first; local changes are stashed by the switch and restored by its undo.
- **Commit CI associates itself**: a repository whose remote points at the connected GitLab or GitHub instance is linked automatically, so the indicator and its pipelines appear without opening the forge panel first; a renamed project is resolved through its redirect.
