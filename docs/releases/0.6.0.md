# BeeBranch 0.6.0

## Update from the header

- As soon as a signed version is published, a notification offers to install it
  with actual download progress. The “Later” button
  postpones it without hiding it permanently.
- The top bar's update icon directly installs the verified
  package, then restarts the application: no need to go through Settings.
  The Profiles page retains its explicit flow with confirmation.

## Compare two commits without leaving history

- Maj+clic on a second commit opens the A → B diff in the inspector, to the right
  of the graph. Swapping A ↔ B and opening full screen remain within reach.
- “Compare A → B” in multiple selection and “Compare with the current branch”
  use the same panel. No repository mutation is performed.

## Graph on par with the reference client

- Lanes keep a constant 22 px spacing and the column widens with
  history (up to 420 px) instead of squeezing eighteen lanes into 150 px.
- Edges leave the dot horizontally, then join their lane through
  a 7 px rounded elbow. Each lane carries its endpoints and opens or
  stops at the relevant commit, without a line from one edge to the other.
- Commit dots increased to 11 px, saturated eight-lane palette (contrast
  ≥ 4.9:1 on both dark and light backgrounds), drawing bounded to the graph
  column.

## History

- The Date column displays the commit's local time in addition to the day
  (`28 oct. 2026 14:32`).
- Hovering opens a tooltip only if the commit subject is truncated
  on screen; fully readable rows no longer trigger a popup.

## Merge and branches

- “Merge” now creates a real merge commit (`--no-ff`) even when
  a fast-forward is possible, so the graph shows where the two
  branches join. The drag-and-drop “Fast-forward” entry remains available for an
  explicit fast-forward, and the preview announces the result.
- Double-clicking a remote branch whose local tracking branch is
  behind (or divergent) moves its tip to the remote commit before
  checkout, even if it is already active. The operation can be undone; a
  checkout that would overwrite local changes is still rejected by Git.

## Update

- macOS Apple Silicon build signed with a `Developer ID Application` certificate,
  notarized by Apple and stapled (app and DMG).
- The update key remains the same: “Return to the previous version”
  goes back to 0.5.1 via `rollback.json`.
