# BeeBranch 0.4.2

## Updates

- **Automatic restart**: after installation, the application relaunches
  itself on the new version. No need to quit and reopen BeeBranch,
  and no “Restart the application” message. A “Restarting…” indicator
  replaces the button during the last few seconds.
- **Header icon**: when a version is published, a download
  icon appears in the top bar (with an accent dot).
  Clicking opens Settings → Updates. Checks run at startup,
  when the window regains focus and every six hours — without blocking
  the interface and without telemetry.

## macOS signing

- The bundle is now signed with the **Apple Distribution: Nala
  Multimedia** identity. The signature no longer changes between builds, so macOS
  can remember permissions: the OS keychain no longer asks for the
  password on every launch (see below).
- The package remains **non-notarized** (no Developer ID certificate): Gatekeeper
  requests permission on first launch, only once per signature.

## After installation

1. First launch: System Settings → Privacy & Security →
   “Open Anyway” if macOS blocks the binary.
2. First GitLab access: when the OS keychain requests access to
   `beebranch.gitlab`, choose **“Always Allow”**. This permission
   is now remembered by macOS and no longer reappears, either on the next
   launch or after an update.
