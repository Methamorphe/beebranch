# BeeBranch 1.0.1

Correctif de l’authentification HTTPS des dépôts ([#8](https://github.com/Methamorphe/beebranch/issues/8)).

- Fetch, pull et push réutilisent les identifiants de la connexion GitLab/GitHub lorsque les helpers Git existants n’en fournissent pas.
- Les tokens GitLab PAT et OAuth sont pris en charge, ainsi que les tokens GitHub.
- Chaque token reste limité à son hôte et à son port HTTPS. Les secrets temporaires sont supprimés après l’opération.
- Les identifiants Git existants conservent la priorité ; aucune configuration du dépôt n’est modifiée.
