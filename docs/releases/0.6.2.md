# BeeBranch 0.6.2

## Compare only two commits: ⌘/Ctrl+click

- A click on a commit, then ⌘+click (Ctrl+click on Windows/Linux) on
  another: the A → B diff compares only these two trees, even if commits
  lie between them.
- The panel announces only “2 commits selected” and lists only the two
  endpoints; the selection contains only them, which also applies to
  Cherry-pick and Revert.
- Maj+clic keeps its meaning: the entire range between the anchor and the click is
  selected and listed.

## A comparison's diff regains its space

- The patch of an A → B comparison is no longer piled under the file
  list: in the inspector, the commits header and the file list
  shared height with the diff, which ended up reduced to its mode
  bar. The list now takes all the remaining space and scrolls.
- Clicking a compared file opens its diff in the central region, in
  place of the graph, as for local changes: file path at the
  top, × button to return to the graph. The comparison and its list remain
  displayed on the right, and a second click on the row closes the patch.
- Clicking a commit, opening the changes panel or closing the comparison
  also closes the open patch.

## More discreet hover branch list

- Hovering a badge that carries several references opens a list reduced to
  the essentials: no more header with the SHA, no more footer, no more
  type label on each row. Each row keeps the reference icon
  (local branch, remote branch or tag) and its name, at 24 px high.
- Width follows the longest name, capped at 260 px: the list takes
  about half the previous height and no longer hides the graph.
- The type, the active branch state and double-click to checkout remain
  announced by the tooltip and each row's accessible label.

## `origin/HEAD` no longer decorates commits

- Git adds `origin/HEAD` to the decorations of the commit carrying the remote's
  default branch, while it is an alias of that branch, already
  displayed. BeeBranch no longer displays it: neither on the badge nor in the hover
  list, which removes a duplicate “remote” row.

## Verifications

- The headless visual evidence (`scripts/ui-smoke.mjs`) verifies that the comparison
  panel no longer renders a diff, that clicking a file opens the patch
  in the central region (usable width, `aria-current` on the row, modified
  words underlined) and that closing it restores the graph without losing the
  comparison.
- It also covers ⌘/Ctrl+click: `range` query on both clicked SHAs,
  only two commits listed, no intermediate commit retained, and no
  patch open before clicking a file.
- It verifies the hover list: all references listed, width
  ≤ 260 px, `origin/HEAD` absent despite its presence in Git decorations,
  and double-click on a hidden reference that checks out the right branch.
