# BeeBranch 0.4.4

## Verification release (2)

No functional changes. This version exists so that the application on
0.4.3 — which was already the latest — has a newer version to
offer.

- The update icon must appear on its own in the header, without opening
  settings (checks at startup, when the window regains focus, then
  every six hours).
- Installation must relaunch the application on its own on 0.4.4.
- The OS keychain must not ask for the password again: the signature is
  identical to 0.4.3 (Apple Distribution: Nala Multimedia), so
  the “Always Allow” permission already granted remains valid.

Rollback available: `rollback.json` points to 0.4.3, signed.
