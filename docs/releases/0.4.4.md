# BeeBranch 0.4.4

## Release de vérification (2)

Aucun changement fonctionnel. Cette version existe pour que l'application en
0.4.3 — qui était déjà la plus récente — ait une version plus récente à
proposer.

- L'icône de mise à jour doit apparaître seule dans l'en-tête, sans ouvrir les
  réglages (vérification au démarrage, au retour de focus sur la fenêtre, puis
  toutes les six heures).
- L'installation doit relancer l'application d'elle-même sur 0.4.4.
- Le trousseau ne doit pas redemander le mot de passe : la signature est
  identique à celle de 0.4.3 (Apple Distribution : Nala Multimedia), donc
  l'autorisation « Toujours autoriser » déjà accordée reste valable.

Retour arrière disponible : `rollback.json` pointe 0.4.3, signé.
