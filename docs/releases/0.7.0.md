# BeeBranch 0.7.0

## Splash screen

- At launch, a small frameless window displays the BeeBranch logo
  animation, then gives way to the main window as soon as the interface has
  rendered its first frame. The main window stays hidden during
  the animation: no empty window flash, no unstyled frame.
- The splash screen stays visible for at least 2.4 s (reduced animation if
  `prefers-reduced-motion`), and an 8 s safety timeout opens the main
  window even if the interface does not respond.

## GitHub

- Connection to github.com or GitHub Enterprise Server via a Personal Access
  Token, stored in the `beebranch.github` OS keychain — separate from GitLab.
- Repository listing and search, repository ↔ GitHub project association, graph
  badges and clone picker.
- Pull requests: my PRs, to review, assigned, project; detail, creation,
  reviews and approvals, review comments, CI checks and Actions job
  logs.
- Documented REST API limitations in `docs/06-github.md`:
  thread resolution, auto-merge and branch deletion on merge remain
  in the GitHub interface.

## Tabs and opening repositories

- The `+` button opens an “Open a repository” tab reusing home:
  recent repositories, local directory, creation and cloning. The clone form
  is displayed in this tab; Escape or the cross close it.
- Browser-style tabs: middle-click to close, drag and drop to
  reorder (Escape cancels), order preserved from one session to the next
  (`ui.openRepos`).

## Graph and history

- Full context menu on a commit or branch: checkout, worktree,
  cherry-pick, soft or mixed reset, revert, SHA and web link copying, lightweight
  and annotated tags, patch, pull fast-forward, push, upstream, fast-forward /
  merge / rebase between branches, local and remote deletions, pinning,
  solo, opening a merge request. Reset exposes only reversible
  modes.
- Pin a branch on the left (lane preserved per repository in
  `ui.graph.pins`); **Solo** isolates a branch in the graph filter.
- Stashes drawn as nodes at the top of history, with a distinct
  medallion and the entered message; the `index` and `untracked` snapshots no
  longer pollute the tree.
- Rounded-corner direction revised: a branch joining its parent keeps its column
  until the parent's row and curves above the median.

## Files and commit

- Multiple file selection: checkboxes, Maj+clic range, grouped
  Stage / Unstage / Discard actions, detailed confirmation before a
  multiple discard.
- Collapsible tree of modified files (single-child directories
  compacted, per-directory counter), option remembered in `ui.status.view`.
- ⌘/Ctrl + Enter creates the commit; the success return allows copying the SHA
  or undoing the commit.
- Inspector as a drawer under 1120 px: commit detail, comparison and
  commit preparation are displayed as an overlay, without compressing the graph.

## Status bar and ergonomics

- Interactive status bar: branch, counters, conflicts, operation in progress and
  GitLab status are clickable; the Operations menu displays the recent journal and
  allows undoing the last operation.
- Zoom bounded between 50% and 200% in 10% steps (⌘/Ctrl `+` / `-`, ⌘/Ctrl
  `0` to reset); wheel and pinch no longer change
  zoom.
- Progressive toolbar: secondary actions move to icons then
  into the Actions menu; “Search” becomes “Commands”.
- Feedback: short flash on staging, operation change animation,
  discreet commit success appearance.

## Update

- Signed and notarized macOS bundles, signed `latest.json` manifest (minisign) and
  `rollback.json` retaining version 0.6.4 to roll back from
  Settings → Updates.
