# BeeBranch 0.7.1

## Repository opening tab

- ⌘/Ctrl + T (or the tabs' `+` button) opens the home tab with the
  “Search a recent repository…” field already focused; the query resets
  to zero on each new tab.
- The filter covers the repository name and path, the list displays
  “N of M repositories”, Enter opens the first result, and the absence of
  a match is signaled by a message.
- The “New tab” shortcut appears in Preferences → Shortcuts and in
  the command palette.

## Pull, fetch and push: failures are no longer silent

- The engine now checks the exit code of synchronization
  commands. A rejected `git pull` — divergent branch, fast-forward
  impossible, rejected credentials, untracked file in the path — surfaces
  an error with the full Git output. Previously the operation was announced
  as “done” with no change at all, which gave the impression that the pull
  did nothing.
- Two error codes dedicated to pull rejections: “The pull could not be integrated
  as a fast-forward” (`pull.ff=only` and divergent branches) and “Git requires a
  strategy to reconcile divergent branches”. Other rejections
  reuse the existing messages (authentication, dirty worktree, untracked
  files that would be overwritten, repository busy).

## Visible pull result

- The toolbar indicates what the pull actually did:
  `Pull: already up to date.`, `Pull: abc1234 → def5678.`, or
  `Pull incomplete: N commits still behind.` when Git succeeded without
  integrating what it had just fetched.
- This message is tied to the repository that produced it: it disappears when
  switching tabs and no longer describes another repository.

## Git configuration respected

- The pull strategy follows Git's order: `branch.<name>.rebase`, then
  `pull.rebase`, then `pull.ff`. Only `pull.rebase` was read and `--no-rebase`
  was imposed, which forced a merge on users configured for
  rebase or `pull.ff=only`.

## Update

- Signed and notarized macOS bundles, signed `latest.json` manifest (minisign) and
  `rollback.json` retaining version 0.7.0 to roll back from
  Settings → Updates.
