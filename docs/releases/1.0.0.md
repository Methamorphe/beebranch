# BeeBranch 1.0.0

First stable version of BeeBranch, published under AGPL-3.0.

## Key points

- **French / English interface**: typed catalog, language chosen from the
  system then in Settings → General, without restart. Dates, numbers,
  backend errors and undo labels follow the active language.
- **Workspace picker**: opens all the repositories of a
  workspace in one gesture (`⌘⇧W` or the tab bar), reuses already open
  repositories, keeps tabs with an operation in progress.
- **Connection without a new token**: reuse of the machine's Git
  credentials (`git credential fill`, macOS keychain, Windows
  Credential Manager, `gh auth git-credential`) for GitLab and GitHub.
- **OAuth device flow**: GitHub.com and GitLab.com connection via a code to enter
  in the browser; the `device_code` and tokens stay on the backend,
  in the OS keychain.
- **Custom background and splash screen**: image or GIF, without
  exposing the file system to the webview.
- **Redesigned secondary screens**: merge requests, pull requests, search,
  rebase, file history, worktrees, tags, remotes, submodules,
  patches and synchronization share a full-width surface, dense
  rows and explicit states.
- **Explicit fast-forward**: the merge dialog offers fast-forward
  or the merge commit, and the engine passes `--ff`, `--ff-only` or `--no-ff`.
- **Stashes dated in the graph**, with apply, apply + drop and
  confirmed deletion.
- **Git hooks displayed**, resumption after interruption and confirmed
  destructive actions.

## Distribution

| Platform | Artifact |
|---|---|
| macOS (Apple Silicon) | `BeeBranch_1.0.0_aarch64.dmg` — signed `Developer ID Application`, notarized and stapled |
| Windows (x64) | `BeeBranch_1.0.0_x64-setup.exe` — NSIS installer |
| Linux (x86_64) | `.AppImage`, `.deb`, `.rpm` |

Updates are minisign-signed and verified before installation;
`rollback.json` retains the previous version.

## Update from 0.7.2

The update endpoint changed: versions ≤ 0.7.2 do not see this
release. Reinstall BeeBranch 1.0.0 from this repository's releases.

## Compatibility

- Git ≥ 2.34
- GitLab 19.3–19.5 (feature detection beyond) and GitLab.com
- GitHub.com and GitHub Enterprise Server (REST v3)
- The built-in GitLab.com OAuth requires `BEEBRANCH_GITLAB_CLIENT_ID` at
  compile time; self-hosted instances use their own Git
  credentials or a Personal Access Token.
