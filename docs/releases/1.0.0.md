# BeeBranch 1.0.0

Première version stable de BeeBranch, publiée sous AGPL-3.0.

## Points clés

- **Interface français / anglais** : catalogue typé, langue choisie selon le
  système puis dans Réglages → Général, sans redémarrage. Les dates, nombres,
  erreurs backend et libellés d'annulation suivent la langue active.
- **Sélecteur de workspace** : ouverture en un geste de tous les dépôts d'un
  workspace (`⌘⇧W` ou la barre d'onglets), réutilisation des dépôts déjà
  ouverts, conservation des onglets en cours d'opération.
- **Connexion sans nouveau token** : réutilisation des identifiants Git de la
  machine (`git credential fill`, keychain macOS, Gestionnaire d'identifiants
  Windows, `gh auth git-credential`) pour GitLab et GitHub.
- **OAuth device flow** : connexion GitHub.com et GitLab.com par code à saisir
  dans le navigateur ; le `device_code` et les jetons restent côté backend,
  dans le keychain de l'OS.
- **Arrière-plan et écran de démarrage personnalisés** : image ou GIF, sans
  exposer le système de fichiers au webview.
- **Écrans secondaires refondus** : merge requests, pull requests, recherche,
  rebase, historique de fichier, worktrees, tags, remotes, sous-modules,
  patches et synchronisation partagent une surface pleine largeur, des lignes
  denses et des états explicites.
- **Avance rapide explicite** : le dialogue de fusion propose l'avance rapide
  ou le commit de fusion, et le moteur passe `--ff`, `--ff-only` ou `--no-ff`.
- **Stashs datés dans le graphe**, avec application, application + retrait et
  suppression confirmée.
- **Hooks Git affichés**, reprise après interruption et actions destructives
  confirmées.

## Distribution

| Plateforme | Artefact |
|---|---|
| macOS (Apple Silicon) | `BeeBranch_1.0.0_aarch64.dmg` — signé `Developer ID Application`, notarié et agrafé |
| Windows (x64) | `BeeBranch_1.0.0_x64-setup.exe` — installateur NSIS |
| Linux (x86_64) | `.AppImage`, `.deb`, `.rpm` |

Les mises à jour sont signées minisign et vérifiées avant installation ;
`rollback.json` conserve la version précédente.

## Mise à jour depuis 0.7.2

L'endpoint de mise à jour a changé : les versions ≤ 0.7.2 ne voient pas cette
release. Réinstaller BeeBranch 1.0.0 depuis les releases de ce dépôt.

## Compatibilité

- Git ≥ 2.34
- GitLab 19.3–19.5 (feature detection au-delà) et GitLab.com
- GitHub.com et GitHub Enterprise Server (REST v3)
- L'OAuth intégré GitLab.com nécessite `BEEBRANCH_GITLAB_CLIENT_ID` à la
  compilation ; les instances auto-hébergées utilisent leurs propres
  identifiants Git ou un Personal Access Token.
