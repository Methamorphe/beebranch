## P3-T01 — Full Undo / Redo

**Depends on:** P1-T12

**Deliverables**

- Implementation of the matrix in [04-undo-redo](../04-undo-redo.md).
- Fingerprints and preconditions.
- No application backup: Git inverse only.
- Transactional restoration and reflog-based recovery panel.
- Bounded redo.
- Crash and partial failure tests.

**Acceptance criteria**

- Each undoable operation restores the exact `before` status.
- A violated precondition refuses without effects.
- A partial failure is reported with the recovery command and SHA.
- No non-undoable operation is presented as undoable.
- No untracked file deleted.
- No working tree copy created by the application.

**Tests:** full matrix, fault injection, crash, full disk.

**Out of scope:** undoing a push.

## P3-T02 — Advanced drag & drop

**Depends on:** P2-T01, P2-T03

**Deliverables**

- Dragging a branch onto a branch (merge/rebase).
- Reordering commits in interactive rebase.
- Preview and cancellation.
- Operation confirmation.

**Acceptance criteria**

- No ambiguous mutation.
- The preview matches the result.
- Cancellation before drop changes nothing.
- Conflicts are handled.

**Tests:** E2E drag & drop, cancellation, conflicts.

## P3-T03 — Design system, themes and animations

**Depends on:** P1

**Deliverables**

- Tokens (colors, spacing, typography, density).
- Light/dark themes.
- Non-blocking animations, respecting `prefers-reduced-motion`.
- Base components.

**Acceptance criteria**

- No animation blocks an action.
- Contrasts meet the chosen level.
- Themes are consistent across all views.
- No performance regression.

**Tests:** visual, contrast, reduced motion.

## P3-T05 — Multi-repository workspaces

**Depends on:** P1-T07

**Deliverables**

- Local repository groups.
- Multi-repository fetch/pull.
- Status overview.
- Bounded and cancellable actions.

**Acceptance criteria**

- A multi-repository action reports the result per repository.
- One failure does not cancel the others.
- No repository modified without confirmation.
- Memory stays bounded.

**Tests:** 10 repositories, partial failure, performance.

## P3-T06 — Accessibility

**Depends on:** P2-T06

**Deliverables**

- Full keyboard navigation.
- Visible focus and logical order.
- ARIA roles and labels.
- Contrasts.
- Screen reader compatibility on the main views.

**Acceptance criteria**

- All main actions can be performed with the keyboard.
- Focus is never trapped.
- Error messages are announced.
- The chosen level is verified by an audit.

**Tests:** automated audit + manual tests.

## P3-T07 — Distribution and updates

**Depends on:** P0-T01

**Deliverables**

- Windows/macOS/Linux packaging.
- Signing and notarization.
- Signed update mechanism.
- Release notes.
- No telemetry.

**Acceptance criteria**

- An unsigned binary is refused by the update.
- Installation works on a clean machine.
- Rollback is possible.
- No data sent without user action.

**Tests:** installation, update, signature, rollback.
