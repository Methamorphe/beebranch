# P2 — Fiches de tâches

**Statut : implémenté dans la version 0.3.0.** Preuves et correspondance fiche → code/tests : [docs/reviews/p2-review.md](../reviews/p2-review.md).

Fiches compactes. Même DoD que P0/P1 : comportement réel, tests, preuve.

---

## P2-T01 — Rebase interactif

**Dépend de :** P1-T05

**Livrables :** todo généré par l'application, helper `GIT_SEQUENCE_EDITOR`/`GIT_EDITOR`, actions pick/reword/squash/drop, réordonnancement, conflits, abort/continue, reset du plan.

**Critères d'acceptation**

- Le todo correspond exactement au plan validé.
- Reword et squash produisent les messages attendus.
- Un conflit est visible et gérable.
- Aucun todo corrompu, aucun commit de base supprimé.
- Fonctionne sur Windows/macOS/Linux.

**Tests :** fixtures de rebase, conflits, reword/squash, crash pendant rebase.

**Hors périmètre :** drag & drop (P3).

## P2-T02 — Résolution de conflits 3 panneaux

**Dépend de :** P2-T01, P1-T05

**Livrables :** base/ours/theirs/output, édition, sélection de blocs, marquage résolu, enregistrement, navigation.

**Critères d'acceptation**

- Les trois versions proviennent des stages Git corrects.
- L'édition ne corrompt pas les marqueurs.
- Le marquage résolu met à jour l'index.
- Un fichier binaire ou trop gros est traité explicitement.
- L'abort reste possible.

**Tests :** conflits textuels, binaires, gros fichiers, absence de newline, CRLF.

## P2-T04 — Worktrees

**Dépend de :** P0-T03

**Livrables :** liste, création, ouverture, lock/unlock, suppression, statut par worktree, ouverture dans un nouvel onglet.

**Critères d'acceptation**

- Chaque worktree a sa session et son statut.
- Une suppression refuse un worktree sale sans confirmation.
- Les refs partagées sont cohérentes.
- Aucun cache mélangé entre worktrees.

**Tests :** fixtures multi-worktrees, suppression sale, lock.
